## Key files for deployment

### Render (primary, free)

- `render.yaml` — Blueprint (build + start command, health check)
- `requirements.txt` — dependencies

### Railway

- `main.py` — entry point (`railway.toml`'s start command)
- `railway.toml` / `nixpacks.toml` — build + start configuration

### Docker

- `Dockerfile` — container build, runs `gunicorn api.app:app`

### Vercel

- `api/app.py`, `vercel.json`, `requirements.txt` (auto-detected)

See [DEPLOYMENT.md](DEPLOYMENT.md) for full instructions.

## Core application

- `api/app.py` — Flask app, all API endpoints
- `api/option_pricing.py` — Black-Scholes, Greeks, Newton-Raphson/Brent IV solvers
- `api/advanced_models.py` — Monte Carlo (GBM/Heston/jump-diffusion), stress testing
- `api/iv_engine.py` — the NSE terminal's core: per-strike IV solving, put-call-parity
  rate derivation, and skew fitting
- `api/india_market_data.py` — real NSE F&O option chains and RBI rates
- `api/templates/index.html` + `api/static/` — the terminal UI
