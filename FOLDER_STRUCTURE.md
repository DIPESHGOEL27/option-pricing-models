## Key files for deployment

### Railway (primary)

- `main.py` — entry point (`railway.toml`'s start command)
- `railway.toml` / `nixpacks.toml` — build + start configuration
- `requirements.txt` — dependencies

### Docker

- `Dockerfile` — container build, runs `gunicorn api.app:app`

### Vercel (Black-Scholes/Monte Carlo only — no ML)

- `api/app.py`, `vercel.json`, `requirements-vercel.txt`

See [DEPLOYMENT.md](DEPLOYMENT.md) for full instructions.

## Core application

- `api/app.py` — Flask app, all API endpoints
- `api/option_pricing.py` — Black-Scholes and Greeks
- `api/advanced_models.py` — Monte Carlo, Heston, stress testing
- `api/ml_pricing.py` — ML pricing ensemble (neural network, random forest, XGBoost)
- `api/templates/index.html` + `api/static/` — the dashboard
